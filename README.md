# Лабораторна робота №5. Варіант 2

Програма моделює коливання математичного маятника з використанням бібліотеки SFML, та системи збирання CMake  та пакетного менеджера vcpkg у режимі маніфесту.

* **Мова:** C++17
* **Графіка та вікна:** SFML
* **Збирання:** CMake + `CMakePresets.json`
* **Залежності:** `vcpkg`
* **Середовище розробки:** Visual Studio

## Структура проєкту
* `CMakeLists.txt` 
* `CMakePresets.json` 
* `vcpkg.json` 
* `main.cpp` 
* `resources/fonts/`

## Керування
* `Up` `Down` — збільшити або зменшити довжину підвісу.
* `Left` `Right` — змінити початковий кут відхилення.
* `Space` пауза.
* `R` повторний запуск.

## Результати обчислювального експерименту
Дослідження проводилося при фіксованому початковому куті відхилення та різних значеннях довжини підвісу L:

| № | Довжина підвісу L,| Початковий кут, deg | Виміряний період T, s |
| :--- | :--- | :--- | :--- |
| 1 | 160.0 | 45.0 | 3.24 |
| 2 | 360.0 | 45.0 | 4.86 |
| 3 | 240.0 | 45.0 | 3.97 |

При збільшенні довжини підвісу період коливань маятника зростає: зі збільшенням довжини з 160.0 до 240 і 360.0 px виміряний період зріс з 3.24 3.97 і 4.86 s. Залежність періоду від довжини підвісу є нелінійною та зростає повільніше за саму довжину.
